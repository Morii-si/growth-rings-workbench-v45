# Permissions

本 Demo 没有账号、角色、token、服务端访问控制或数据库/RLS。唯一使用者是当前浏览器操作者；其本机同源存储可被本人及同源脚本读取。`demo-session` 提供存档隔离，不提供访问授权。

| 资源 | 允许操作 | 执行边界 / 拒绝条件 |
| --- | --- | --- |
| 打包案例、财报、V1/V2 与批准的完整 V3 | 任何页面访问者阅读 | V3 存档已获用户明确公开演示授权，包含用户原话与小结；其余恢复备份和浏览器存档不公开。历史范围仍受展示/model 逻辑约束 |
| 当前存档的讨论、未发送文字、引用 | 当前浏览器读取、追加、导出 | key 由 `resolveResearchSession()` 派生；session id 仅接受 1–80 位字母、数字、`_`、`-`；无跨设备共享权限 |
| 当前 V3 研究看板 | 生成；引用后通过聊天提出修改，显式更新 | 无用户消息不能生成；不存在的类目、变化后的目标、非法提议被 model 拒绝 |
| 已保存历史快照 | 阅读、导出；后续修改追加新快照 | 当前 UI 不提供直接覆盖旧快照的入口；深拷贝防止普通操作联动改写，不防本机调试篡改 |
| 独立开场演示 | 新建空会话 key、恢复该 key、返回普通完整作品 | 新演示不注入批准 V3、不删除普通 key；同浏览器知道 key 的操作者仍能访问，没有角色隔离 |
| 精确旧存档迁移备份 | 本机保存旧 raw 字符串，读回核对后迁移 | 只匹配已确认的完整旧状态指纹；不同备份不覆盖。失败时保留旧状态并阻止写回；备份不上传、不进入发布资源 |
| 全量 JSON 导出 | 当前浏览器下载当前 state | 无过滤或脱敏；分享文件会同时分享其中用户原话、引用、历史及兼容字段 |

文本渲染使用 HTML 转义（如 `conversation-ui.js` 的 `chatEscape`）；它不等于远程输入或导入文件的完整安全校验。当前没有 JSON 上传/导入入口。若之后接入账号、共享看板或远程 AI，必须新增相应服务端授权与数据发送边界，不能复用 storage key 充当权限。
